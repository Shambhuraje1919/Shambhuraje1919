## 💭 About Me

I'm an AI & Machine Learning enthusiast who likes turning messy data into systems that actually do something useful. My background spans classical ML, deep learning, and — more recently — LLM-based applications with LangChain, backed by a competitive programming foundation (1000+ DSA problems in Java) that keeps my fundamentals sharp.

I currently maintain two active learning repos:
- 🧠 **[Generative-AI](https://github.com/Shambhuraje1919/Generative-AI)** — LangChain, LLMs, RAG-building-blocks, embeddings, chains & runnables
- 📊 **[Machine_Learning_Paractice](https://github.com/Shambhuraje1919/Machine_Learning_Paractice)** — 80+ notebooks spanning EDA, feature engineering, classical ML, and deep learning, with a CI pipeline
